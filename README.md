# Название проекта - Сайт — универсальное расписание студента

## О проекте
Будет универсальное расписание студента в котором будет совмещено актуальное расписание колледжа и его личные дела.

## Проблема
Проблема заключается в том что всё запутано:  нет единого места расписания, доски объявлений и личных заметок. 

## Цель
Создать универсальный сайт с актуальным расписанием и со всеми делами студента

## Основные функции первой версии
1. Просматривание расписания колледжа
2. Просматривание доски объявления
3. Добавление/изменение заметок
