# Название проекта - Редактируемое расписание для сайта  колледжа

## О проекте
Будет редактируемое расписание Для сайта колледжа, в котором можно будет добавлять и изменять расписание и личные дела.

## Проблема
Проблема заключается в том что всё сложно устроено. Нет актуального расписания, студенты по знают что задано. 

## Цель
Создать универсальный сайт для просмотра расписания

## Основные функции первой версии
1. Просматривание расписания колледжа
2. Просматривание личное расписание
3. Добавление заметок
